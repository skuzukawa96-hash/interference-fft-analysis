# 干渉分光スペクトル フーリエ変換解析ツール

干渉分光法で得られた波長 (nm) 対 反射率の干渉スペクトルをフーリエ変換し、
干渉縞の周期成分を評価するツールです。

- 本体: [ir_ft_analysis.py](ir_ft_analysis.py)
- 検証用データ生成: [make_testdata.py](make_testdata.py)
- 自己テスト: [test_ir_ft_analysis.py](test_ir_ft_analysis.py)
- 初心者向けの詳しい解説: [CODE_GUIDE.md](CODE_GUIDE.md)
- 使用ライブラリ: 標準ライブラリ, numpy, pandas, matplotlib, seaborn, scikit-learn

## 2 つの変換ドメイン

`--domain` で FFT の独立変数を選べます。

| 指定 | 独立変数 | 共役軸 (FFT の出力) | 主な用途 |
|---|---|---|---|
| `wavelength` (既定) | 波長 λ [nm] | 波数 [波数/100nm] | 波長ごとの縞の細かさ |
| `wavenumber` | 波数 1/λ [1/nm] | 光路差 OPD [nm] = 2nd | 膜厚・光路差の測定 |
| `both` | 両方を実行 | | 比較したいとき |

干渉縞の位相は 2nd/λ で決まるため、縞は本来 1/λ に対して等間隔に並びます。
広い帯域をまとめて解析するときや膜厚を求めたいときは `wavenumber` が適しています。
詳細と実例は [CODE_GUIDE.md](CODE_GUIDE.md) の第 4 章を参照してください。

## 入力データ形式

| Wavelength (nm) | 2 | 4 | 6 | … |
|---|---|---|---|---|
| 200 | 0.3486 | 0.6979 | 0.3927 | … |
| 200.5 | 0.3473 | 0.6973 | 0.3978 | … |

- **A 列**: 干渉光の波長 (nm)
- **B 列以降**: 各条件での反射率。**列名 (1 行目) は条件を表す数値**であること
- 列名が数値でない列、全て空の列は自動的に除外されます
- 波長軸が等間隔でない場合は、等間隔グリッドへ自動で再サンプリングします
- 列内の欠測値は補間で埋めます

## 使い方

### 基本

```bash
python ir_ft_analysis.py --input dataset.csv --band 300-600 --window hann
```

`--input` を省略するとカレントディレクトリの `dataset.csv` を読み込みます。

### 引数なしで起動 (対話モード)

波長帯域・ドメイン・窓関数を対話的に入力できます。

```bash
python ir_ft_analysis.py
```

### 膜厚を求める (波数ドメイン)

```bash
python ir_ft_analysis.py -i dataset_film.csv -b 700-1000 --domain wavenumber -n 1.5 --zero-pad 8 --refine-peak
```

`-n` に屈折率を渡すと、光路差から膜厚 d = OPD/(2n) を推定した列が出力に加わります。

### 複数帯域・両ドメインをまとめて解析

```bash
python ir_ft_analysis.py -b 200-400 -b 300-600 -b 600-1000 --domain both
```

### 窓関数の一覧

```bash
python ir_ft_analysis.py --list-windows
```

| 窓関数 | 特徴 |
|---|---|
| `rectangular` (`none`) | 窓なし。分解能は最良だが漏れが大きい |
| `hann` | 汎用。既定値 |
| `hamming` | 第一サイドローブが低い |
| `blackman` | 漏れが小さくメインローブは広い |
| `bartlett` | 三角窓 |
| `blackmanharris` | サイドローブ -92 dB |
| `nuttall` | 漏れが非常に小さい |
| `flattop` | 振幅精度が最良 (位置の精度は劣る) |
| `kaiser` | `--kaiser-beta` で漏れと分解能を調整 |

### 主なオプション

| オプション | 既定値 | 説明 |
|---|---|---|
| `-i, --input` | `dataset.csv` | 入力 CSV |
| `-b, --band LO-HI` | 全波長域 | フーリエ変換する波長帯域。複数指定可 |
| `-d, --domain` | `wavelength` | FFT の独立変数。`wavelength` / `wavenumber` / `both` |
| `-w, --window` | `hann` | 窓関数 |
| `--kaiser-beta` | `8.6` | カイザー窓の β |
| `--detrend` | `linear` | FFT 前のトレンド除去 (`none` / `mean` / `linear`) |
| `--zero-pad` | `1` | ゼロ詰め倍率。>1 で共役軸を細かく補間 |
| `--interp` | `cubic` | グリッド再配置の補間。波数ドメインで効く |
| `--peak-min` | `0` | ピーク探索の下限 (既定は直流成分のみ除外) |
| `--refine-peak` | off | 放物線近似でピーク位置をサブビン精度に補正 |
| `-n, --refractive-index` | なし | 屈折率。波数ドメインで膜厚を推定 |
| `--xmax` | `auto` | フーリエスペクトル図の横軸上限。数値 / `auto` / `nyquist` |
| `-o, --outdir` | `output` | 出力ディレクトリ |
| `--no-raw-plot` | off | 変換前の信号の図を出力しない |
| `--show` | off | グラフを画面表示する |

## 出力

`output/band_<下限>-<上限>nm_<lambda|sigma>_*` として以下が生成されます。

| ファイル | 内容 |
|---|---|
| `*_fourier_spectrum.png` | フーリエスペクトルの折れ線グラフ。各列の最大ピークを丸印で表示 |
| `*_peak_regression.png` | 条件 対 ピーク位置の散布図。回帰直線・式・決定係数・ナイキスト限界の破線・交点を表示 |
| `*_raw_spectra.png` | 変換に投入した信号 (確認用) |
| `*_peaks.csv` | 列ごとの条件・ピーク位置・振幅・ナイキスト比・限界近接フラグ |
| `*_fourier_spectrum.csv` | 全条件のフーリエスペクトルの数表 |
| `*_summary.json` | 解析条件、ナイキスト限界、回帰係数、決定係数、到達条件 |

## 計算の定義

### 共役軸の単位

波長ドメインでは、FFT が返す周波数は 1 nm 当たりの波数です。100 倍して
**波数/100nm** としています。

```
波数 [/100nm] = f [/nm] × 100
```

波数ドメインでは、独立変数が 1/λ [1/nm] なので共役軸は長さ [nm]、すなわち
**光路差 OPD** そのものになります。

### ナイキスト限界

サンプリング間隔から導出します。

```
波長ドメイン: 100 / (2 Δλ)   [波数/100nm]
波数ドメイン: 1 / (2 Δ(1/λ)) [nm]
```

付属データは Δλ = 0.5 nm なので、波長ドメインでは **100 波数/100nm** です。

### 分解能

```
分解能 = 共役軸の単位係数 / (N × サンプリング間隔)      N: 帯域内のデータ点数
```

300–600 nm (601 点, Δλ = 0.5 nm) では 0.333 波数/100nm です。
条件間の差がこれより小さいと分離できないため、帯域を広げるか
`--zero-pad` と `--refine-peak` でピーク位置を補間してください。

### 振幅

窓関数のコヒーレントゲイン (窓係数の総和) で正規化し、片側スペクトルを 2 倍
しています (直流とナイキスト成分は 2 倍しません)。これにより振幅は入力信号の
正弦波成分の振幅そのものになります。

### ナイキスト到達条件

条件 x に対するピーク位置 y の回帰直線 `y = a x + b` と、
ナイキスト限界 `y = f_nyq` の交点として求めます。

```
ナイキスト到達条件 = (f_nyq − b) / a
```

測定条件の範囲外になる場合は外挿である旨を図と出力に明示します。

## 自己テスト

```bash
python test_ir_ft_analysis.py
```

全窓関数の復元精度、回帰とナイキスト到達条件、エイリアシング、光路差と膜厚の復元、
補間方式の比較、振幅正規化、不等間隔・欠測データへの耐性、引数パーサを検証します
(45 項目)。

## 付属テストデータでの結果 (dataset.csv, 300–600 nm, hann 窓, 波長ドメイン)

| 条件 | 振幅最大の波数 [/100nm] | 最大ピーク振幅 |
|---|---|---|
| 2 | 0.3328 | 0.1204 |
| 4 | 0.6656 | 0.2038 |
| 6 | 0.9983 | 0.1981 |
| 8 | 1.3311 | 0.1962 |
| 10 | 1.6639 | 0.1941 |
| 12 | 1.9967 | 0.1914 |
| 14 | 2.3295 | 0.1884 |

- ナイキスト限界: **100 波数/100nm**
- 回帰直線: **y = 0.1664 x + 0**, 決定係数 **R² = 1.0000**
- ナイキスト到達条件: **601** (測定条件範囲外への外挿)

条件 2 のピークだけ振幅が低いのは、300–600 nm の帯域内に干渉縞が
約 1 周期しか入らず、ハン窓で振幅が削られるためです。帯域を広げるか
`--window rectangular` にすると改善します。
