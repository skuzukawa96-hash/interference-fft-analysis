# 干渉分光スペクトル フーリエ変換解析ツール

干渉分光法で得られた波長 (nm) 対 反射率の干渉スペクトルをフーリエ変換し、
干渉縞の周期成分を評価するツールです。

- 本体: [ir_ft_analysis.py](ir_ft_analysis.py)
- 検証用データ生成: [make_testdata.py](make_testdata.py)
- 自己テスト: [test_ir_ft_analysis.py](test_ir_ft_analysis.py)
- 初心者向けの詳しい解説: [CODE_GUIDE.md](CODE_GUIDE.md)
- 使用ライブラリ: 標準ライブラリ, numpy, pandas, matplotlib, seaborn, scikit-learn

## 2 つの変換ドメイン

`--domain` で FFT の独立変数を選べます。

| 指定 | 独立変数 | 共役軸 (FFT の出力) | 主な用途 |
|---|---|---|---|
| `wavelength` (既定) | 波長 λ [nm] | 波数 [波数/100nm] | 波長ごとの縞の細かさ |
| `wavenumber` | 波数 1/λ [1/nm] | 光路差 OPD [nm] = 2nd | 膜厚・光路差の測定 |
| `both` | 両方を実行 | | 比較したいとき |

干渉縞の位相は 2nd/λ で決まるため、縞は本来 1/λ に対して等間隔に並びます。
広い帯域をまとめて解析するときや膜厚を求めたいときは `wavenumber` が適しています。
詳細と実例は [CODE_GUIDE.md](CODE_GUIDE.md) の第 4 章を参照してください。

## ピーク位置の精密化 (グリッドサーチ + Levenberg–Marquardt 法)

FFT が答えられるのは**分解能の刻み (格子点) の上の値だけ**です。`--fit` を付けると、
M. Quinten, *On the use of fast Fourier transform for optical layer thickness
determination*, SN Applied Sciences **1**, 823 (2019) 第 5 章の 2 段階法で、
格子点の間にある真のピーク位置を求めます。

1. **グリッドサーチ**: FFT のピーク f_FFT の周辺 [f_FFT − 2Δf, f_FFT + 2Δf]
   (Δf は分解能) を M 等分し、各点で正弦波モデルとデータの二乗誤差 χ² を計算して最小の点を選ぶ
2. **Levenberg–Marquardt 法**: その点を初期値に、正弦波 + ベースラインのモデルを
   非線形最小二乗フィットする。標準誤差も出力する

```bash
python ir_ft_analysis.py -b 300-600 --fit lm
python ir_ft_analysis.py -i dataset_film.csv -b 700-1000 --domain wavenumber -n 1.5 --fit lm
```

| `--fit` | 内容 |
|---|---|
| `none` (既定) | FFT のピーク位置をそのまま使う |
| `grid` | グリッドサーチまで。精度は 4Δf/M 程度 |
| `lm` | グリッドサーチ + LM 法。最も正確で、標準誤差も得られる |

付属データでの最大誤差 (真値との差):

| データ | FFT のみ | FFT + 放物線補間 | `--fit grid` | `--fit lm` |
|---|---|---|---|---|
| `dataset.csv` 300–600 nm [/100nm] | 0.101 | 0.060 | 0.040 | **7×10⁻¹¹** |
| `dataset_highfreq.csv` 200–1000 nm [/100nm] | 0.056 | 3.9×10⁻⁵ | 0.013 | **1.6×10⁻⁵** |
| `dataset_film.csv` 波数ドメイン [nm] | 1100 | 1.2 | 270 | **0.10** |

LM 法は追加ライブラリなしで numpy だけで実装しています。波数ドメインでは
1/λ グリッドへ補間する前の点に直接フィットするので、補間誤差も入りません。
フィットの決定係数が 0.9 を下回る列は、正弦波モデルが合っていない (縞間隔が帯域内で
変化している等) として警告を出します。仕組みは [CODE_GUIDE.md](CODE_GUIDE.md) の第 6 章を参照してください。

## 膜厚測定の拡張 (論文のその他の手法)

同じ論文 (Quinten 2019) の、膜厚測定に特有の問題への対策も使えます。
いずれも波数ドメイン (`--domain wavenumber`) で使います。

| 手法 | 論文 | オプション |
|---|---|---|
| 分散を考慮した有効屈折率 n_eff と膜厚の分解能 | 式 6, 7 | `--cauchy A,B[,C]` / `--n-table CSV` |
| 隣接する極大の位置から膜厚を求める | 式 8 | `--fringe` |
| 多重反射の反射率モデルで膜厚をフィット | 式 1, 15 | `--fit-model reflectance` (+ `--substrate-n` / `--substrate-table`) |
| パワースペクトル × m² の重み付きピーク探索 | 第 4 章 | `--peak-weight m2` |
| 吸収による最大膜厚の目安 | 式 17 | 屈折率テーブルに k があれば自動表示 |

```bash
python ir_ft_analysis.py -i dataset_dispersion.csv -d wavenumber --cauchy 1.56,0.005 --substrate-n 3.6 --fit-model reflectance --fringe
python ir_ft_analysis.py -i dataset_background.csv -d wavenumber -n 1.5 --peak-weight m2
```

**膜の屈折率の与え方** (いずれか 1 つ):

- `-n 1.5`: 一定の値。n_eff = n なので従来どおり
- `--cauchy 1.56,0.005`: Cauchy の式 n = A + B/λ² + C/λ⁴ (λ: µm)
- `--n-table film.csv`: 1 列目 波長 [nm]、2 列目 n、3 列目 k (任意) の CSV。点の間は線形補間

分散のある膜 (`dataset_dispersion.csv`、Si 基板上、膜厚 2〜50 µm) での膜厚の誤差:

| 方法 | 5〜50 µm での最大誤差 |
|---|---|
| FFT・一定の屈折率 (帯域中央の値) | 2.6 % |
| FFT・有効屈折率 (式 7) | 0.59 % |
| 隣接極大 (式 8) | **0.009 %** |
| 反射率モデル + LM (式 1) | **0.003 nm** |

強いベースラインに弱い縞が乗ったデータ (`dataset_background.csv`) では、
通常の探索はベースラインの残りを拾って全条件で失敗し、`--peak-weight m2` では全条件で
縞のピークを正しく検出しました。ただし重みは高い位置のノイズも強調するので、
低い位置に偽のピークが出ているときだけ使ってください。

なお論文の式 5 は FFT の最大膜厚を (N − 1)·d_min としていますが、実数データ N 点の FFT で
区別できるのは約 (N/2)·d_min までです。本ツールは N/2 を限界として扱います。
詳細と実装していない項目は [CODE_GUIDE.md](CODE_GUIDE.md) の第 7 章を参照してください。

## 入力データ形式

| Wavelength (nm) | 2 | 4 | 6 | … |
|---|---|---|---|---|
| 200 | 0.3486 | 0.6979 | 0.3927 | … |
| 200.5 | 0.3473 | 0.6973 | 0.3978 | … |

- **A 列**: 干渉光の波長 (nm)
- **B 列以降**: 各条件での反射率。**列名 (1 行目) は条件を表す数値**であること
- 列名が数値でない列、全て空の列は自動的に除外されます
- 波長軸が等間隔でない場合は、等間隔グリッドへ自動で再サンプリングします
- 列内の欠測値は補間で埋めます

## 使い方

### 基本

```bash
python ir_ft_analysis.py --input dataset.csv --band 300-600 --window hann
```

`--input` を省略するとカレントディレクトリの `dataset.csv` を読み込みます。

### 引数なしで起動 (対話モード)

波長帯域・ドメイン・窓関数を対話的に入力できます。

```bash
python ir_ft_analysis.py
```

### 膜厚を求める (波数ドメイン)

```bash
python ir_ft_analysis.py -i dataset_film.csv -b 700-1000 --domain wavenumber -n 1.5 --fit lm
```

`-n` に屈折率を渡すと、光路差から膜厚 d = OPD/(2n) を推定した列が出力に加わります。
`--fit lm` を併用すると膜厚の標準誤差の列も付きます。

### 複数帯域・両ドメインをまとめて解析

```bash
python ir_ft_analysis.py -b 200-400 -b 300-600 -b 600-1000 --domain both
```

### 窓関数の一覧

```bash
python ir_ft_analysis.py --list-windows
```

| 窓関数 | 特徴 |
|---|---|
| `rectangular` (`none`) | 窓なし。分解能は最良だが漏れが大きい |
| `hann` | 汎用。既定値 |
| `hamming` | 第一サイドローブが低い |
| `blackman` | 漏れが小さくメインローブは広い |
| `bartlett` | 三角窓 |
| `blackmanharris` | サイドローブ -92 dB |
| `nuttall` | 漏れが非常に小さい |
| `flattop` | 振幅精度が最良 (位置の精度は劣る) |
| `kaiser` | `--kaiser-beta` で漏れと分解能を調整 |

### 主なオプション

| オプション | 既定値 | 説明 |
|---|---|---|
| `-i, --input` | `dataset.csv` | 入力 CSV |
| `-b, --band LO-HI` | 全波長域 | フーリエ変換する波長帯域。複数指定可 |
| `-d, --domain` | `wavelength` | FFT の独立変数。`wavelength` / `wavenumber` / `both` |
| `-w, --window` | `hann` | 窓関数 |
| `--kaiser-beta` | `8.6` | カイザー窓の β |
| `--detrend` | `linear` | FFT 前のトレンド除去 (`none` / `mean` / `linear`) |
| `--zero-pad` | `1` | ゼロ詰め倍率。>1 で共役軸を細かく補間 |
| `--interp` | `cubic` | グリッド再配置の補間。波数ドメインで効く |
| `--peak-min` | `0` | ピーク探索の下限 (既定は直流成分のみ除外) |
| `--refine-peak` | off | 放物線近似でピーク位置をサブビン精度に補正 |
| `-f, --fit` | `none` | ピーク位置の精密化。`none` / `grid` / `lm` |
| `--grid-points` | `16` | グリッドサーチの分割数 M (±2×分解能 を M 等分) |
| `--max-iter` | `100` | LM 法の最大反復回数 |
| `--baseline-degree` | 自動 | 精密化モデルのベースライン多項式の次数 (`--detrend linear` なら 1、それ以外は 0。反射率モデルは 0) |
| `--peak-weight` | `none` | ピーク探索の重み。`m2` でパワースペクトル × m² (論文の第 4 章) |
| `-n, --refractive-index` | なし | 膜の屈折率 (一定)。波数ドメインで膜厚を推定 |
| `--cauchy A,B[,C]` | なし | 膜の屈折率を Cauchy の式で与える (λ: µm)。有効屈折率 (式 7) を使う |
| `--n-table CSV` | なし | 膜の屈折率テーブル (波長 nm, n, k) |
| `--substrate-n` / `--substrate-k` | `1.0` / `0` | 基板の屈折率 (反射率モデル用。1.0 は自立膜) |
| `--substrate-table CSV` | なし | 基板の屈折率テーブル |
| `--fit-model` | `sinusoid` | 精密化のモデル。`reflectance` で多重反射の反射率の式 (論文の式 1, 15) |
| `--fringe` | off | 隣接する極大の位置から膜厚を求める (論文の式 8) |
| `--xmax` | `auto` | フーリエスペクトル図の横軸上限。数値 / `auto` / `nyquist` |
| `-o, --outdir` | `output` | 出力ディレクトリ |
| `--no-raw-plot` | off | 変換前の信号の図を出力しない |
| `--show` | off | グラフを画面表示する |

## 出力

`output/band_<下限>-<上限>nm_<lambda|sigma>_*` として以下が生成されます。

| ファイル | 内容 |
|---|---|
| `*_fourier_spectrum.png` | フーリエスペクトルの折れ線グラフ。各列の最大ピークを丸印、精密化した位置と振幅を + 印で表示 |
| `*_peak_regression.png` | 条件 対 ピーク位置の散布図。回帰直線・式・決定係数・ナイキスト限界の破線・交点を表示。精密化時は FFT の値を白抜きで重ねる |
| `*_fit_check.png` | 精密化時のみ。帯域の端の数周期でデータとフィット曲線を重ねた確認図 |
| `*_raw_spectra.png` | 変換に投入した信号 (確認用) |
| `*_peaks.csv` | 列ごとの条件・ピーク位置・振幅・ナイキスト比・限界近接フラグ。精密化時は FFT/グリッドの値、標準誤差、フィットの R² なども追加 |
| `*_fourier_spectrum.csv` | 全条件のフーリエスペクトルの数表 |
| `*_summary.json` | 解析条件、精密化の方式、ナイキスト限界、回帰係数、決定係数、到達条件 |

精密化した場合、`*_peaks.csv` のピーク位置の列 (`peak_wavenumber_per_100nm` /
`peak_opd_nm`) には**精密化後の値**が入り、回帰もその値で行います。
FFT の値は `fft_` で始まる列に残ります。反射率モデルでは、膜厚を光路差に換算した値
2·n_eff·d が入ります。

波数ドメインで膜の屈折率を与えると、膜厚 (`estimated_thickness_nm`、光路差 / 2n_eff) が
付きます。`--fringe` では式 8 の膜厚 (`fringe_thickness_nm` と標準誤差・ペア数)、
反射率モデルでは倍率 (`fit_scale`、理想は 1) も付きます。`*_summary.json` の
`thickness` に n_eff・膜厚の分解能・最大膜厚などがまとめて記録されます。

## 計算の定義

### 共役軸の単位

波長ドメインでは、FFT が返す周波数は 1 nm 当たりの波数です。100 倍して
**波数/100nm** としています。

```
波数 [/100nm] = f [/nm] × 100
```

波数ドメインでは、独立変数が 1/λ [1/nm] なので共役軸は長さ [nm]、すなわち
**光路差 OPD** そのものになります。

### ナイキスト限界

サンプリング間隔から導出します。

```
波長ドメイン: 100 / (2 Δλ)   [波数/100nm]
波数ドメイン: 1 / (2 Δ(1/λ)) [nm]
```

付属データは Δλ = 0.5 nm なので、波長ドメインでは **100 波数/100nm** です。

### 分解能

```
分解能 = 共役軸の単位係数 / (N × サンプリング間隔)      N: 帯域内のデータ点数
```

300–600 nm (601 点, Δλ = 0.5 nm) では 0.333 波数/100nm です。
FFT のピーク位置はこの刻みでしか得られません。位置を正確に求めたいときは
`--fit lm` を使ってください。なお、近接した 2 つの縞を分離する能力そのものは
精密化しても変わらないので、その場合は帯域を広げてください。

### 振幅

窓関数のコヒーレントゲイン (窓係数の総和) で正規化し、片側スペクトルを 2 倍
しています (直流とナイキスト成分は 2 倍しません)。これにより振幅は入力信号の
正弦波成分の振幅そのものになります。

### ナイキスト到達条件

条件 x に対するピーク位置 y の回帰直線 `y = a x + b` と、
ナイキスト限界 `y = f_nyq` の交点として求めます。

```
ナイキスト到達条件 = (f_nyq − b) / a
```

測定条件の範囲外になる場合は外挿である旨を図と出力に明示します。

## 付属テストデータでの結果 (dataset.csv, 300–600 nm, hann 窓, 波長ドメイン)

| 条件 | FFT の波数 [/100nm] | FFT の振幅 | `--fit lm` の波数 [/100nm] | `--fit lm` の振幅 |
|---|---|---|---|---|
| 2 | 0.3328 | 0.1204 | 0.318310 | 0.2000 |
| 4 | 0.6656 | 0.2038 | 0.636620 | 0.2000 |
| 6 | 0.9983 | 0.1981 | 0.954930 | 0.2000 |
| 8 | 1.3311 | 0.1962 | 1.273240 | 0.2000 |
| 10 | 1.6639 | 0.1941 | 1.591549 | 0.2000 |
| 12 | 1.9967 | 0.1914 | 1.909859 | 0.2000 |
| 14 | 2.3295 | 0.1884 | 2.228169 | 0.2000 |

| 項目 | FFT のみ | `--fit lm` |
|---|---|---|
| 回帰直線 | y = 0.1664 x + 0 | **y = 0.15915 x** (= x / 2π) |
| 決定係数 | 1.0000 | 1.0000 |
| ナイキスト到達条件 | 601 | **628.3** (= 200π) |

ナイキスト限界は **100 波数/100nm** です。LM 法の結果は全列でフィットの
決定係数 1.00000000、振幅 0.200000 となり、このデータの真の波数は**条件 / 2π**
であることがわかります。FFT のみでは帯域内に縞が 1〜7 周期しかなく刻みが粗いため、
傾きを約 4.5 % 過大に、ナイキスト到達条件を約 4 % 過小に見積もっていました。
